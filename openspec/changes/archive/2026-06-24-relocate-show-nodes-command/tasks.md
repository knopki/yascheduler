Body: compute `enabled_axis_active = args.enabled != args.disabled` (True iff exactly one of them is set); `busy_axis_active = args.busy != args.free`; `cloud_filter = args.cloud if args.cloud is not None else (None if not args.no_cloud else "NO_CLOUD_SENTINEL")` — simpler: branch explicitly. Concretely, build a list of predicate functions and apply all:
  - If `args.enabled and not args.disabled`: predicate `r.enabled == True`.
  - If `args.disabled and not args.enabled`: predicate `r.enabled == False`.
  - If `args.busy and not args.free`: predicate `r.task_id is not None`.
  - If `args.free and not args.busy`: predicate `r.task_id is None`.
  - If `args.cloud is not None`: predicate `r.cloud == args.cloud` (exact match).
  - If `args.no_cloud` (and `args.cloud is None`, guaranteed by the mutex group): predicate `r.cloud is None`.
  Then `return [r for r in rows if all(pred(r) for pred in predicates)]`. Order preserved (list comprehension over `rows` in order). Add a `START_BLOCK_FILTER` / `END_BLOCK_FILTER` anchor around the predicate list + comprehension. Note: `--json` is NOT a filter (it selects the renderer in `show_nodes`); do not reference `args.json` here.
