- [x] 1.4 Implement `_parse_node_args(argv: list[str] | None = None) -> argparse.Namespace`: `ArgumentParser(prog="yasetnode", description="Add or remove nodes from the yascheduler daemon")`; positional `host` with `type=_parse_host_spec`; flags `--skip-setup`/`--remove-soft`/`--remove-hard` all `action="store_true"`; `--remove-soft` and `--remove-hard` in `mutually_exclusive_group`; body-level `parser.error(...)` when `skip_setup and (remove_soft or remove_hard)`; `parser.parse_args(argv)`. Add contract + `START_BLOCK_PARSE_ARGS` anchors.
- [x] 1.5 Implement `_remove_node_hard(deps, spec) -> None`. The helper opens its OWN UoW via `async with deps.uow_factory() as uow:`; inside it: list RUNNING task ids via `uow.tasks.list_ids_by_ip_and_status(spec.host, TaskStatus.RUNNING)`, mark each DONE, `uow.nodes.remove(spec.host)`, `uow.commit()`; print per-task "An associated task {task_id} at {host} is now marked done!" and "Removed host from yascheduler: {host}" **after** commit (all inside the helper's UoW). Add contract + `START_BLOCK_` anchors.
- [x] 1.6 Implement `_remove_node_soft(deps, spec) -> None`. The helper opens its OWN UoW via `async with deps.uow_factory() as uow:`; inside it: list RUNNING task ids; if RUNNING tasks exist → `uow.nodes.disable(spec.host)`, `uow.commit()`, print "A task associated, prevent from assigning the new tasks" + "Prevented from assigning the new tasks: {host}"; else → `uow.nodes.remove(spec.host)`, `uow.commit()`, print "No tasks associated, remove node immediately" + "Removed host from yascheduler: {host}". Add contract + `START_BLOCK_` anchors.
- [x] 1.7 Implement `_add_node(deps, gateway, spec, config, skip_setup) -> None`. Username is resolved **inside** `_add_node` as `username = spec.username or config.remote.username`. The helper opens its OWN UoW via `async with deps.uow_factory() as uow:`. Body: `try:` `gateway.connect(ip=spec.host, username=username, client_keys=config.local.get_private_keys(), engines_dir=config.remote.engines_dir, port=spec.port)`, if not `skip_setup` print "Setup host..." + `await gateway.setup_node(spec.host, config.engines)`, `await uow.nodes.add(Node(ip=spec.host, port=spec.port, username=username, ncpus=(spec.ncpus if spec.ncpus is not None else 0), enabled=True))`, `await uow.commit()`, print "Added host to yascheduler: {spec.host}:{spec.port}"; `finally:` `await gateway.disconnect(spec.host)`. The `try/finally` wraps connect→setup→add→commit; disconnect runs on both success and failure. Add contract + `START_BLOCK_` anchors.
- [x] 1.8 Implement `manage_node(argv: list[str] | None = None) -> None` decorated with `@to_sync`: `args = _parse_node_args(argv)`; `logging.captureWarnings(True)` + `log = logging.getLogger(); log.setLevel(logging.WARN)`; `config = Config.from_config_parser(CONFIG_FILE)`; `deps = make_cli_deps(config)`; `gateway = SSHMachineGateway()` (constructed before any UoW); wrap orchestration in `try/except Exception as e: print(f"Error: {e}", file=sys.stderr); sys.exit(1)`; open a short READ-ONLY validation UoW via `async with deps.uow_factory() as uow:` solely to read `already_there = await uow.nodes.get(spec.host) is not None` (closed without commit — nothing mutated); raise `ValueError(f"Host already in DB: {spec.host}")` for already-in-DB-on-add and `ValueError(f"Host NOT in DB: {spec.host}")` for not-in-DB-on-remove; dispatch to exactly one helper, each of which opens its OWN UoW from `deps`: `_remove_node_hard(deps, spec)` / `_remove_node_soft(deps, spec)` / `_add_node(deps, gateway, spec, config, args.skip_setup)` (username resolution delegated to `_add_node`). Add contract + `START_BLOCK_` anchors. (Design D18: per-helper UoW; the validation read and the dispatch mutation are separate transactions, with an accepted TOCTOU window for a single-operator CLI.)
